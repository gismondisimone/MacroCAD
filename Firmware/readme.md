# macrocad

MacroCAD is a KeyPad Design by a CAD user for CAD users

* Keyboard Maintainer: [Simone](https://github.com/gismondisimone)
* Hardware:** Seeed XIAO RP2040
* Hardware Availability: https://github.com/gismondisimone/MacroCAD



## Bootloader

Per entrare in modalità bootloader, tieni premuto il tasto BOOT, premi e rilascia RESET, quindi rilascia BOOT.
